CG Lite is a lightweight CGPA calculator built for BITS Pilani students. It installs to the home screen as a progressive web app, needs no account, and keeps every grade on the device. After the first visit it works with no connection at all.

### Key Features
*   **Built-In Course Catalog:** About 707 BITS courses with codes and credit counts, so adding a course is a search rather than manual entry.
*   **Accurate BITS Grading:** Uses the institute's grade scale to compute SGPA and CGPA per semester, including summer terms.
*   **Degree Progress:** The summary screen tracks credits against the 144-credit requirement, counts core, open, humanities and discipline electives, and charts SGPA across semesters.
*   **Private by Default:** All data lives in local storage, with export and import for backups or moving to a new phone.
*   **Works Offline:** A Serwist service worker precaches the app shell and assets, so it opens and runs with no network, like a native app.
*   **Personalisation:** Accent colour themes and a choice between overall CGPA and CGPA up to the selected semester.
