This project is the official digital home for the Association for Computing Machinery (ACM) student chapter at BITS Pilani, Hyderabad Campus. It serves as a central hub for our chapter's activities, events, team, and resources.

### Key Features
*   **Modern UI/UX:** Built with Next.js and Tailwind CSS for a responsive and visually appealing experience.
*   **Interactive Elements:** Features animated components and smooth transitions using Framer Motion to engage users.
*   **Team Showcase:** An interactive carousel displays the chapter leadership and team members.
*   **Project Showcase:** A dedicated section featuring projects developed by chapter members, complete with detailed descriptions and the specific tech stacks used.
*   **Domains Section:** A dedicated section that dives into the work and projects undertaken by each domain within the club.
*   **Blog:** Chapter posts are stored in Supabase and rendered from Markdown.
*   **Events Calendar:** Provides clear information about upcoming and past chapter events.
*   **Responsive Design:** Fully optimized for a seamless experience on all device sizes, from mobile to desktop.
